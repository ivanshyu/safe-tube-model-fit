# ExtractModel-Safe ⚡

**Transient-Safe SPICE Vacuum Tube Model Fitting Engine & Subcircuit Generator**

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![ngspice Compatible](https://img.shields.io/badge/ngspice-46%2B%20Compatible-green.svg)](https://ngspice.sourceforge.io/)

`ExtractModel-Safe` is an advanced Python fitting engine and SPICE code generator for vacuum tube models (Triodes, Pentodes, Beam Tetrodes) based on **Derk Reefman's ExtractModel V4** theory.

It solves critical numerical instabilities, denominator singularities, and ngspice compatibility bugs found in standard ExtractModel exports, allowing high-gain tube audio amplifier circuits (such as RKV, OTL, and power output stages) to execute **1.5-second cold-start startup transient simulations in ngspice 46 without timestep collapse or convergence failure**.

## 💥 Critical Numerical Problems Solved

Standard SPICE tube models generated by ExtractModel 4.x work well for positive DC sweeps ($V_a > 0$), but frequently fail during transient simulations when cold-start power supply ramp-up causes plate voltages to temporarily drop below zero ($V_a < 0$).

### 1. Singularity Pole at $V_a = -1/\beta$
* **The Problem**: In Derk's pentode model, screen current is modeled as $I_{g2} \propto 1 / (1 + \beta V_a)$. When cold-start transients push plate voltage to $V_a = -1/\beta$ (e.g. $V_a = -16.02\text{V}$ for PL805 with $\beta = 0.0624$), the denominator becomes zero. Current explodes to $\pm \infty$, triggering ngspice `timestep collapse`.
* **The Solution**: Introduces C¹-continuous, smooth positive effective voltage regularization:
  $$V_{a,\text{eff}} = 0.5 \cdot \left(V_a + \sqrt{V_a^2 + 0.01}\right)$$
  For $V_a \ge 0$, $V_{a,\text{eff}} \approx V_a$ (preserving 100% curve accuracy). For $V_a < 0$, $V_{a,\text{eff}} > 0$, guaranteeing $1 + \beta V_{a,\text{eff}} \ge 1.0 > 0$ with zero denominator poles anywhere on $(-\infty, +\infty)$.

### 2. `ngspice 46` `LIMIT()` and `IF()` Syntax Compatibility Bugs
* **The Problem**:
  - `IF()` functions inside `VALUE={...}` return `no such function 'if'` in ngspice 46.
  - `LIMIT(x, a, b)` in ngspice 46 is a tolerance/variation function, **not** a numeric clamp! Evaluating `LIMIT(2.579, -50, 50)` returned `-47.421` or `52.579`, causing plate currents to explode to 3.5 Amps and DC operating grid voltages to offset to $+7.7\text{kV}$!
* **The Solution**: Replaces `IF()` with smooth C¹ exponential cutoff:
  $$E_{\text{CUTOFF}} = \exp\left( \frac{V_a - \sqrt{V_a^2 + 10^{-4}}}{4.0} \right)$$
  And replaces all `LIMIT(x, a, b)` statements with exact numeric clamping:
  $$\text{MIN}(\text{MAX}(x, a), b)$$

### 3. Newton-Raphson Intermediate Step NaNs in `PWR()`
* **The Problem**: Even when final node voltages are positive, Newton-Raphson matrix solver intermediate iterations can temporarily pass negative values into node $V(7)$. When power exponent $EX$ is non-integer (e.g. $1.2784$), `PWR(V(7), EX)` returns `NaN`, aborting transient simulation with `trouble with DZ_18`.
* **The Solution**: Inlines smooth positive protection directly inside `PWR()` expressions:
  ```spice
  E_IP 80 0 VALUE={ PWR(0.5 * (V(7) + SQRT(V(7)*V(7) + 1e-12)), 1.2784) }
  ```
  And directly inlines safe denominators inside `G1` and `G2` current sources.

### 4. Log-Space Multi-Start Nelder-Mead Optimization
* **The Problem**: Tube parameters span over 20 orders of magnitude ($A \approx 10^{-14}$, $S \approx 10^{-14}$, $k_{g2} \approx 4000$). Traditional single-point linear Nelder-Mead gets trapped in local minimum (yielding RMSE $\approx 12.89\text{mA}$).
* **The Solution**: Optimizes in log-space ($y = \ln p$) across multiple initial parameter seeds (including EM4 reference values and nested $S=0$ seeds). For a 4-file 880-point PCL805 dataset, fitting RMSE dropped to **7.78 mA** (beating the EM4 baseline of 8.10 mA!).

## ⚡ Installation & Quick Start

### Requirements
- **Python 3.8+** (Zero third-party dependencies required! Standard library only).
- **ngspice 46+** (for circuit simulation).

### Installation
Clone the repository:
```bash
git clone https://github.com/ivanshyu/safe-tube-model-fit.git
cd safe-tube-model-fit
```

## 🛠️ Usage Examples

### 1. Fit Triode Model (`E92CC.utd`)
```bash
python3 fit_utd_model.py --model triode -n E92CC_Triode -o E92CC.cir E92CC.utd
```

### 2. Multi-Screen Joint Fitting for Power Pentode (`PCL805`)
To accurately resolve secondary emission and screen current parameters ($\lambda, \nu, w$), pass multiple `.utd` files recorded at different screen voltages ($V_s$):
```bash
python3 fit_utd_model.py --model derk-se \
  --name PCL805_Safe \
  --output PCL805_Safe.cir \
  PCL805-Vs125.utd PCL805-Vs170.utd PCL805-Vs190.utd PCL805-Vs210.utd
```

### CLI Command Options
```text
usage: fit_utd_model.py [-h] -m {triode,derk,derke,derk-se} [-n NAME] [-o OUTPUT] [-q] utd_files [utd_files ...]

positional arguments:
  utd_files             Input .utd measurement data file(s). Multiple files allow multi-screen joint fitting.

options:
  -h, --help            Show this help message and exit
  -m, --model           Target tube model type (REQUIRED: triode, derk, derke, derk-se)
  -n, --name            Subcircuit name in generated SPICE code (default: SafeTubeModel)
  -o, --output          Optional output filepath to save generated SPICE subcircuit (.cir file)
  -q, --quiet           Suppress informational stdout logs
```
